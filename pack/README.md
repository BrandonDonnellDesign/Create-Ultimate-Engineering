# Pack export goes here

Copy the real export from your existing CurseForge profile into this directory:

- `manifest.json` — copied from the CurseForge profile export.
- `overrides/` — the export's overrides directory, including configs/scripts/resources owned by this pack.

Do not replace the real manifest with a hand-written template. It must contain the correct CurseForge project/file IDs, Minecraft version, and mod loader.
